# 语音交互APP项目

## 项目架构

本项目实现了一款与客户语音交互的APP，具有以下功能：
- 根据录入的声音复制为AI的声音和人互动对话
- 根据描述的性格特征，对话方式等与客户开展不断深入的对话
- 关键技术点是声音的情感、对话方式、语气语调模拟

## 核心功能

1. **语音采集与处理**
   - 麦克风实时采集（AudioRecord）
   - WebRTC VAD语音活动检测
   - WebRTC实时传输（UDP协议）
   - 音频播放

2. **语音定义渠道**
   - VoxCPM2语音定义
     - 根据用户描述和参考音频定义语音风格
     - 支持个性化语音定制
     - 生成语音嵌入用于后续对话

3. **端到端语音模型**
   - 方案A：Fun-Audio-Chat-8B（推荐）
     - 原生全双工支持
     - 支持实时打断
     - 情感感知和语气模拟
     - 端到端语音处理
   - 方案B：Whisper + Llama 3 8B + Edge TTS（备选）
     - 语音识别 + 大语言模型 + 文本转语音
     - 需额外实现打断处理

3. **记忆管理**
   - 短期记忆：Redis存储最近的对话历史
   - 长期记忆：Milvus存储重要的对话内容
   - 性格向量：FAISS存储用户性格特征

4. **安全与可靠性**
   - JWT认证鉴权
   - HTTPS加密传输（Caddy自动证书）
   - 限流保护
   - 健康检查

## 技术栈

- **客户端**：iOS (Swift), Android (Kotlin)
- **接入层**：Kong Gateway, Caddy
- **核心AI**：Python, PyTorch, Fun-Audio-Chat-8B, VoxCPM2
- **数据库**：Redis, Milvus, FAISS
- **基础设施**：GPU服务器（RTX 3090）, OSS, SLS, Prometheus, GitLab

## 部署说明

### 1. 客户端部署
- **iOS**：使用Xcode构建
  - 集成WebRTC库
  - 配置音频权限
- **Android**：使用Android Studio构建
  - 集成WebRTC库
  - 配置音频权限

### 2. 服务端部署

#### 2.1 接入层
- **Kong Gateway**：
  - 配置 `kong.conf`
  - 启动：`kong start -c kong.conf`
- **Caddy**：
  - 配置 `Caddyfile`
  - 启动：`caddy run --config Caddyfile`

#### 2.2 核心AI服务
- **环境配置**：
  - Python 3.8+
  - PyTorch 2.0+
  - CUDA 11.7+
- **模型下载**：
  - Fun-Audio-Chat-8B：从Hugging Face下载
- **启动服务**：
  ```bash
  cd ai-service
  python main.py
  ```

#### 2.3 数据库服务
- **Redis**：
  - 启动：`redis-server`
- **Milvus**：
  - 启动：`milvus-server`
- **FAISS**：
  - 集成在AI服务中

### 3. 硬件要求
- **GPU**：单张RTX 3090（24GB）
- **CPU**：8核以上
- **内存**：32GB以上
- **存储**：100GB以上

## 注意事项

1. **模型部署**：
   - Fun-Audio-Chat-8B需要24GB GPU内存
   - 建议使用NVMe SSD存储模型文件

2. **性能优化**：
   - 使用FP16精度推理
   - 配置合适的批处理大小
   - 启用GPU缓存

3. **安全配置**：
   - 替换JWT密钥
   - 配置Caddy的DNS API令牌
   - 设置合适的限流规则

4. **监控与维护**：
   - 配置Prometheus监控GPU和服务状态
   - 设置告警规则
   - 定期备份数据库

5. **扩展建议**：
   - 高并发场景可考虑多GPU部署
   - 全球用户可考虑多区域部署
   - 可集成更多语音模型以支持不同场景
