### ⚠️ 部署注意

**pip-audit 扫描 requirements.txt 时检测到 pillow/datasets/fsspec 旧版本漏洞**，因为：
1. 这些是传递依赖（pillow 通过 transformers → accelerate 引入；datasets/fsspec 通过 voxcpm 引入）
2. voxcpm 声明 `datasets<4` 与 5.0.1 冲突
3. requirements.txt **故意不写**这些包（pip-audit 会因声明冲突误报）

**生产部署必须两步安装**：
```bash
pip install -r ai-service/requirements.txt -r api-gateway/requirements.txt
pip install pillow==13.0.0 datasets==5.0.1 fsspec==2026.6.0  # 强制覆盖传递依赖
```
