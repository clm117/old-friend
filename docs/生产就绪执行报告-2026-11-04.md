## 五、遗留风险

1. **旧 JWT 密钥已在公开仓库历史中**：轮换后旧值失效，但提交 `5da6aab` 仍在 `origin/main`；公开缓存/fork 可能长期保留。若合规要求“不可检索”，需执行历史改写。
2. **云 TTS 欠费**：当前 `TTS_PROVIDER=cloud` 依赖 DashScope，账户欠费会导致合成失败；生产需监控该错误码并准备降级。
3. **accelerate 无上游修复**：已固定版本并禁止 `trust_remote_code`，仍需持续跟踪上游公告与模型来源审计。
4. **备份文件未加密**：归档含账号口令哈希与业务数据，需存放在受控目录并加密/限权；恢复脚本会保留 rollback 副本，注意磁盘与敏感数据清理。
5. **单实例限流**：未配置 Redis 时限流为进程内内存，多实例部署会放大配额；生产建议启用 `redis` profile。
6. **auth-init 强依赖口令**：未设置 `AUTH_SEED_PASSWORD` 会按设计失败退出，需在首次部署文档中明确。
7. **合规页面需法务复核**：隐私政策/用户协议中的联系方式、保存期限为占位或通用表述，上线前需按实际主体与业务补齐。
8. **Compose 未运行时验证**：端口、卷、健康检查、`depends_on` 条件仅通过静态审查，需在 Docker 环境完成一次真实拉起。
