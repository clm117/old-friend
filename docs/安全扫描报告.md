## 二、任务 10：基础渗透自测（网关接口）

测试环境：本地 gateway :8005（auth_required=false 模式）

### 2.1 通过项（10/10）

| 测试项 | 结果 | 说明 |
|---|---|---|
| 未授权访问受保护接口 | ✅ 401 | 无 token / 伪造 / 过期 token 均被拒绝 |
| SQL 注入（登录） | ✅ 401 | 4 种 payload 均返回"账号或密码错误"，无信息泄露 |
| 路径遍历 | ✅ 404 | `../`、URL 编码路径均被拦截 |
| XSS 反射 | ✅ 401 | payload 未被执行，统一返回认证错误 |
| 超大文件上传 | ✅ 413 | 15MB > 10MB 限制，正确拒绝 |
| 伪造音频格式 | ✅ 400 | EXE 魔数被识别，拒绝非音频格式 |
| 空参数校验 | ✅ 422/400 | 空 description、超长 session_id 均被拦截 |
| 登录限流 | ✅ 429 | 第 4 次请求即触发限流（5次/分钟） |
| /metrics 公开 | ✅ 200 | 可访问（预期行为，生产需 nginx 内网限制） |
| 错误信息泄露 | ✅ 无堆栈 | 仅返回字段校验错误，无敏感信息 |

### 2.2 观察项

1. **登录限流生效较快**：第 4 次即 429，说明滑动窗口计数正常，但 SQL 注入测试时前 3 次也触发 429（因与登录限流共享计数器），属正常行为。
2. **/metrics 公开**：当前本地环境无鉴权，生产部署时应在 nginx 层限制仅内网可达（已在 [可观测性部署指南.md](file:///d:/ProgramFile/语伴/docs/可观测性部署指南.md) 中注明）。
