# 《人工智能拟人化互动服务管理暂行办法》合规自查清单

- 依据：国家网信办等五部门令第 21 号，2026-04-10 公布，**2026-07-15 施行**
- 自查对象：语伴（语音交互 + 角色人格 + 长期记忆 + 情感配置）
- 自查日期：2026-11-12
- 适用范围结论：**适用**。第二条构成要件为「模拟自然人人格特征 + 持续性情感互动 + 音频等形式」，语伴三项全中（角色引擎、WebSocket 实时语音、长期会话记忆）。改写文案不改变认定。

> 说明：下表「现状」基于当前仓库检索结果；标注「未见」的项表示代码与页面中未发现对应实现，落地前需再复核一次。

## 六、验收口径

1. 所有 P0 项必须有可复现的测试用例，不接受「文案已改」作为唯一证据。
2. 第 18 条三项（标识、2 小时、依赖提醒）与第 19 条（退出）属于**不可豁免项**，任何版本不得关闭。
3. 第 13 条干预链路必须做误伤率与漏检率双向验证。
4. 未实测项在报告中标注「未验证」及原因，不得以 mock 结果充抵。

## 七、罚则提示

违反本办法，一般情形警告、通报批评、责令限期改正，可要求暂停注册；拒不改正或情节严重，责令停止服务并处 1 万–10 万元罚款；涉及危害公民生命健康且有后果的，并处 10 万–20 万元罚款。实际成本主要来自下架、约谈整改与停服，而非罚款金额本身。
