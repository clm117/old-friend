# 语伴生产服务器部署指南

## 一、GPU 服务器选型建议

### 推荐配置
| 配置项 | 最低要求 | 推荐配置 | 说明 |
|--------|---------|---------|------|
| GPU 显存 | 16GB | 24GB+ | 8B 模型 fp16 约 16GB，需预留余量 |
| GPU 型号 | RTX 3090 | RTX 4090 / A10 | 推理性能与稳定性 |
| CPU | 8 核 | 16 核 | 并发处理能力 |
| 内存 | 32GB | 64GB | 模型加载与缓存 |
| 系统盘 | 100GB SSD | 200GB SSD | 操作系统与基础软件 |
| 数据盘 | 500GB SSD | 1TB SSD | 模型文件、日志、音频产物 |

### 云服务器推荐
- **阿里云**：gn7i 系列（A10）、gn6v 系列（V100）
- **腾讯云**：GN10X 系列（V100）、GN7 系列（T4）
- **AutoDL**：按小时计费，适合测试阶段

## 二、操作系统与驱动基线

### Ubuntu 22.04 LTS 安装
```bash
# 更新系统
sudo apt update && sudo apt upgrade -y

# 安装基础工具
sudo apt install -y curl wget vim git htop net-tools

# 安装 NVIDIA 驱动
sudo apt install -y nvidia-driver-535
sudo reboot

# 验证驱动
nvidia-smi

# 安装 NVIDIA Container Toolkit
distribution=$(. /etc/os-release;echo $ID$VERSION_ID)
curl -s -L https://nvidia.github.io/nvidia-docker/gpgkey | sudo apt-key add -
curl -s -L https://nvidia.github.io/nvidia-docker/$distribution/nvidia-docker.list | sudo tee /etc/apt/sources.list.d/nvidia-docker.list
sudo apt update && sudo apt install -y nvidia-container-toolkit
sudo systemctl restart docker
```

## 三、主机安全加固

### 防火墙配置
```bash
# 仅放行 22/80/443
sudo ufw allow 22/tcp
sudo ufw allow 80/tcp
sudo ufw allow 443/tcp
sudo ufw enable

# 禁用密码登录，使用密钥
sudo vim /etc/ssh/sshd_config
# 修改：PasswordAuthentication no
# 修改：PermitRootLogin no
sudo systemctl restart sshd
```

### fail2ban 安装
```bash
sudo apt install -y fail2ban
sudo cp /etc/fail2ban/jail.conf /etc/fail2ban/jail.local
sudo systemctl enable fail2ban
sudo systemctl start fail2ban
```

## 四、磁盘与显存规划

### 分区建议
```
/           系统盘 100GB
/models     模型存储 200GB（VoxCPM2 + Fun-Audio-Chat-8B）
/logs       日志存储 100GB
/data       数据存储 200GB（会话、角色、音频产物）
swap        交换分区 32GB
```

### 挂载配置
```bash
# 创建目录
sudo mkdir -p /models /logs /data

# 挂载数据盘（假设为 /dev/vdb）
sudo mkfs.ext4 /dev/vdb
sudo mount /dev/vdb /data

# 写入 fstab
echo '/dev/vdb /data ext4 defaults 0 0' | sudo tee -a /etc/fstab
```

## 五、时间同步与日志留存

### NTP 配置
```bash
sudo apt install -y chrony
sudo systemctl enable chrony
sudo systemctl start chrony

# 验证
chronyc sources
```

### 日志留存（logrotate）
```bash
sudo vim /etc/logrotate.d/yuban
# 内容：
/logs/*.log {
    daily
    rotate 180
    compress
    delaycompress
    missingok
    notifempty
}
```

## 六、备份与恢复演练

### 备份脚本
```bash
#!/bin/bash
# /data/backup.sh

BACKUP_DIR="/data/backups/$(date +%Y%m%d)"
mkdir -p $BACKUP_DIR

# 备份账号表
cp /app/authdata/users.json $BACKUP_DIR/

# 备份会话数据（如有）
# cp -r /app/sessions $BACKUP_DIR/

# 备份角色配置
cp -r /app/character_engine $BACKUP_DIR/

# 压缩归档
tar -czf $BACKUP_DIR.tar.gz $BACKUP_DIR
rm -rf $BACKUP_DIR

# 保留最近 30 天
find /data/backups -name "*.tar.gz" -mtime +30 -delete
```

### 定时任务
```bash
crontab -e
# 添加：每天凌晨 2 点备份
0 2 * * * /data/backup.sh
```
